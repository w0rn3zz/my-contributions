# Полный срез личного вклада

Этот каталог дополняет тематические подборки из `../contributions/`. Здесь собраны **все 311 уникальных путей**, затронутых моими 77 прямыми non-merge коммитами в командном репозитории.

- `current/` — 237 файлов в их актуальном состоянии на момент экспорта: Go-код, React/TypeScript, стили, SQL-миграции, тесты, Docker/CI-конфигурация, OpenAPI и документация;
- `historical/` — 64 файла, которые были перенесены или удалены в последующих рефакторингах. Для каждого указан исходный коммит, содержащий последнюю версию файла, написанную мной;
- 10 путей соответствуют операциям удаления, поэтому их содержимое не существует ни в одном из моих прямых коммитов. Они остаются зафиксированными в `../provenance/original-commits.patch`.

Этот каталог предназначен для ревью вклада, а не для самостоятельного запуска: он сохраняет исходные относительные пути командного репозитория, но не включает файлы, которые я не менял.

## Быстрая навигация

- `current/backend/` — backend, доменная модель, миграции и тесты;
- `current/frontend/` — пользовательский интерфейс, frontend-тесты и стили;
- `current/deploy/`, `current/Makefile`, `current/.github/` — запуск, gateway и CI;
- `historical/` — ранние версии модулей до архитектурных рефакторингов.
